## 🚀 如何使用

本文件夹就是 D 盘上的普通学习资料，**不需要任何额外的软件配置**。

- `.ipynb` 是 Jupyter 笔记本。想运行代码时，用任意支持 Jupyter 的工具打开即可
  （VS Code、Jupyter Notebook、JupyterLab 等都可以），打开后把内核选成
  `Python 3.12.x`，就能逐个单元格运行。
- 不运行也没关系：每个笔记本里的代码、运行结果和中文讲解都写在文件里，
  直接当文本打开也能看懂。
- `.md` 文件（README、公式速查表）用任意文本编辑器打开即可。

### 如果单元格报错"需要 ipykernel 包"

## 📚 学习路线建议

1. 先看 **01 描述性统计**：学会用几个数字概括数据。
2. 再看 **02 概率与分布**、**03 中心极限定理**：打好推断的地基。
3. 然后是 **04 置信区间** → **05 假设检验**：统计推断的两大核心。
4. 最后 **06 相关与回归**：进入预测与建模。

每个笔记本都可以**改数字、看变化**，这是学统计最快的方式。
