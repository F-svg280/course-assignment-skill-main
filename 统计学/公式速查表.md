# 统计学公式速查表

> 配合 `D:\统计学资料` 里的笔记本使用。n = 样本量，x̄ = 样本均值，s = 样本标准差，μ = 总体均值，σ = 总体标准差。

---

## 一、描述性统计

| 名称 | 公式 | 说明 |
|---|---|---|
| 均值 | x̄ = (Σxᵢ) / n | 对极端值敏感 |
| 中位数 | 排序后中间的数 | 稳健，尤其适合偏态数据 |
| 众数 | 出现次数最多的值 | 适合分类数据 |
| 极差 | R = x_max − x_min | 最简单，但只看两端 |
| 样本方差 | s² = Σ(xᵢ − x̄)² / (n − 1) | 分母 n−1 是无偏校正 |
| 样本标准差 | s = √(s²) | 与数据同单位，最常用 |
| 变异系数 | CV = s / x̄ × 100% | 无量纲，可比较不同量纲 |
| 四分位距 | IQR = Q₃ − Q₁ | 箱线图用；异常值界：Q₁−1.5·IQR / Q₃+1.5·IQR |
| 偏度 | Sk = n/((n−1)(n−2)) · Σ((xᵢ−x̄)/s)³ | >0 右偏，<0 左偏，≈0 对称 |
| 峰度 | 见笔记本 01 | >0 尖峰厚尾，≈0 接近正态 |

## 二、概率与分布

**概率加法法则**
```
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
```

**条件概率 / 独立**
```
P(A|B) = P(A ∩ B) / P(B)
独立：P(A ∩ B) = P(A)·P(B)
```

**期望与方差**
```
E(X) = Σ x·P(x)          Var(X) = E(X²) − [E(X)]²
```

**常见分布**

| 分布 | 记号 | 均值 | 方差 |
|---|---|---|---|
| 二项 | B(n, p) | np | np(1−p) |
| 泊松 | Poisson(λ) | λ | λ |
| 均匀 | U(a, b) | (a+b)/2 | (b−a)²/12 |
| 正态 | N(μ, σ²) | μ | σ² |

**正态分布密度函数**
```
f(x) = 1/(σ√(2π)) · e^(−(x−μ)²/(2σ²))
```

**标准正态 / Z 分数**
```
Z = (X − μ) / σ   ~  N(0, 1)
```
经验法则：约 68% 在 μ±σ，95% 在 μ±2σ，99.7% 在 μ±3σ。

## 三、抽样与中心极限定理

| 名称 | 公式 |
|---|---|
| 样本均值的期望 | E(x̄) = μ |
| 标准误（均值） | SE = σ / √n |
| 标准误（比例） | SE = √( p̂(1−p̂) / n ) |

**中心极限定理**：n 足够大时，x̄ 近似服从 N(μ, σ²/n)，无论总体分布如何。

## 四、置信区间

| 情形 | 公式 |
|---|---|
| 均值（σ 已知 / 大样本） | x̄ ± z_(α/2) · (σ/√n) |
| 均值（σ 未知 / 小样本，t） | x̄ ± t_(α/2, n−1) · (s/√n) |
| 比例（大样本） | p̂ ± z_(α/2) · √( p̂(1−p̂)/n ) |

常用临界值：

| 置信度 | z_(α/2) |
|---|---|
| 90% | 1.645 |
| 95% | 1.960 |
| 99% | 2.576 |

> 区间宽度：置信度↑ → 变宽；n↑ 或离散度↓ → 变窄。

## 五、假设检验

**检验统计量**

| 检验 | 统计量 |
|---|---|
| 单样本 t | t = (x̄ − μ₀) / (s/√n)，df = n−1 |
| 独立双样本 t | t = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂)（Welch） |
| 配对 t | t = d̄ / (s_d/√n)，df = n−1 |
| 卡方独立性 | χ² = Σ (O − E)² / E，df = (行−1)(列−1) |
| 单因素 ANOVA | F = MS组间 / MS组内 |

**判断规则**：p 值 < α（通常 0.05）→ 拒绝 H₀；否则不拒绝 H₀。

> ⚠️ p 值不是"H₀ 为真的概率"；不拒绝 ≠ 证明 H₀ 成立。

**两类错误**

|  | H₀ 为真 | H₀ 为假 |
|---|---|---|
| 拒绝 H₀ | 第一类错误 α | 正确（功效 1−β） |
| 不拒绝 H₀ | 正确 | 第二类错误 β |

## 六、相关与回归

**协方差**
```
Cov(X, Y) = Σ(xᵢ − x̄)(yᵢ − ȳ) / (n − 1)
```

**皮尔逊相关系数**
```
r = Cov(X, Y) / (s_x · s_y)      取值范围 [−1, 1]
```
- r > 0 正相关，r < 0 负相关，r ≈ 0 无**线性**相关
- r 只度量线性关系，先画散点图

**简单线性回归**
```
ŷ = b₀ + b₁x
b₁ = r · (s_y / s_x)
b₀ = ȳ − b₁·x̄
```

**决定系数**
```
R² = 1 − SS_残差 / SS_总
SS_残差 = Σ(yᵢ − ŷᵢ)²      SS_总 = Σ(yᵢ − ȳ)²
```
R² 表示模型解释的变异比例。

> ⚠️ 相关 ≠ 因果。
